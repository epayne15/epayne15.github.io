FanFormed CIS 300 website - confirmation page update

Open index.html with Live Server. Complete either form on reviews.html or about.html and select Submit. Browser validation will check required fields before navigating to confirmation.html. This is a static classroom demonstration; nothing is saved or sent to a server.

The forms use GET for static page navigation, so entered values can appear in the browser address bar. Do not enter real personal or sensitive information.

The Pacific Trails case study used a PHP server handler to show entered values. This project does not use PHP or server-side processing.
